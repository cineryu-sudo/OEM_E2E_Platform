## 6. To-be 교차 진단 플랫폼(대시보드) 실무자 필수 요건 메모

두 Storyteller가 Round 4에서 직접 제시한 **핑퐁 즉시 종결을 위한 필수 요건**은 다음과 같다:

1. **차량-통신 식별자 자동 통합 검색 (`VIN` Single Search)**:
   - 메모장 복사나 암호 걸린 엑셀 `VLOOKUP`, 연식별 3사 포털 개별 OTP 로그인 없이, 검색창에 **`VIN`(또는 `Request ID`, `ICCID`) 하나만 입력**하면 `VIN ↔ IMEI ↔ EID ↔ ICCID ↔ IMSI ↔ 012 번호(MSISDN) ↔ 담당 MNO(SKT/KT/LGU+) 및 망 세대(3G/LTE/5G)`가 한 줄로 자동 매핑되어 조회되어야 함.
2. **End-to-End 구간별 시그널링 타임라인 대조 뷰 (KST / UTC 병기)**:
   - `[앱 명령 접수(RCV_OK)]` → `[OEM/본사 서버 발송(Submit_SM_Resp / 국제 SMS Hub 인입 여부)]` → `[MNO 코어망 SMS-C → MME SGs 인터페이스 → 기지국(eNodeB) 실제 Paging 송출 시각]` → `[차량 TCU 모뎀 기지국 등록 상태(Attach/Idle/Detach) 및 MT-SMS Delivery Report]` → `[전용 APN 데이터 세션(PDP Context/IP 할당) 및 상향 HTTPS 패킷 응답(방화벽 Reject/Reset 여부)]` → `[차량 배터리 전압 / Deep Sleep 여부]`가 **단일 타임라인(KST 및 UTC 동시 표기)**에 나란히 표시되어야 함.
3. **유럽 본사 L3 및 귀책 부서 제출용 '표준 기술 증적 리포트(Technical Evidence Report)' 원클릭 출력**:
   - 한글 화면 캡처+빨간 네모 박스+수동 영문 번역 노가다를 없애기 위해, 버튼 하나로 **3GPP/GSMA 표준 시그널링 코드와 UTC 타임스탬프가 찍힌 공식 영문/국문 기술 진단 리포트(PDF/CSV/JSON)**가 즉시 생성되어 글로벌 ServiceNow 티켓이나 사내 클라우드/단말팀/MNO 코어망 L3팀에 바로 전달될 수 있어야 함.
4. **안전한 원격 세션 리셋 및 재시도(`Re-trigger` / `Session Reset`) 액션 버튼**:
   - MNO 코어망의 SGs/PDP 세션 꼬임이나 본사 프로비저닝 `Pending` 고착 시, 1차 운영 실무자가 26시간~8일을 기다리지 않고 권한 범위 내에서 **코어망 세션 리셋(Detach/Re-attach 유도) 또는 Wake-up/프로비저닝 재발송(Re-trigger)**을 즉시 실행할 수 있는 제어 기능.
5. **1차 콜센터 상담원용 실시간 한글 원인 분류 가이드 공유**:
   - 상담원이 첫 통화에서 **"지하주차장 음영 / 차량 배터리 보호 Deep Sleep / 통신망 일시 지연"**을 즉시 구분해 안내하고 약관·내규에 따른 즉각 보상 처리를 할 수 있는 직관적 상태 코드 제공.
