# [디자인 보고서] LG U+ Connected Car 관제 화면: 모노톤 정돈 및 인포그래픽/차트 적용안

> **작성 목적**: 현행 텍스트 위주 구성의 가독성 저하와 다채로운 색상 혼란을 해결하고, 모노톤 기반 정돈과 관제 센터급 시각적 인포그래픽/차트 요소를 발굴하여 제안합니다.  
> **레퍼런스 이미지 분석**: 첨부해 주신 글로벌 금융 관제 센터(대형 스크린 대시보드)는 다크 블루/시안 모노톤 베이스에 KPI 링, 라인 추세, 막대형 지표가 정갈한 패널 그리드로 구성되어 있습니다. 이 중 **실제 장애 원인 규명에 직결되는 시각화 요소**를 선별하여 적용합니다.

## 1. 현행 색상 전수 감사 및 모노톤 개편 규칙

### 1.1 현행 코드 색상 남용 실태 진단
- **CSS 및 JS 내 사용 색상 수**: 무려 **18종 이상의 색상 텍스트/보더** 난립 (`#fff`, `#34d399`, `#6ee7b7`, `#94a3b8`, `#f87171`, `#fda4af`, `#fca5a5`, `#fbbf24`, `#ff6b81`, `#fde68a`, `#a7f3d0`, `#7dd3fc`, `#fdba74` 등).
- **문제점**: 
  1. 일반 보조 설명문, 배지, 카드 테두리, 버튼 등에 각양각색의 형광/파스텔톤이 섞여 있어 **"진짜 어디가 장애인지(Red Spot)"**보다 배경 색상들에 시선이 분산됨.
  2. 이모지(`🟢`, `🟡`, `🔴`, `🚨`, `⚡`, `🔍`, `📋`, `🎯`, `🛠️`, `⏱️`, `📄`, `🔗`)가 텍스트마다 붙어 비즈니스 전문 도구라기보다 산만함 유발.

### 1.2 모노톤 + 단일 포인트 하이라이트 규칙 (Strict Monotone System)
텍스트는 **오직 무채색(회색조) 3단계**로만 엄격히 통일하고, 유채색은 오직 '상태 식별자'로만 제한합니다:

| 계층 | 역할 | 적용 색상 토큰 | 대상 |
|---|---|---|---|
| **Primary Text** | 제목, 핵심 수치, 코드값 | `#F8FAFC` (Slate 50) | VIN, Hop 이름, 상태 코드, 주요 수치 |
| **Secondary Text** | 일반 본문, 라벨, 설명 | `#94A3B8` (Slate 400) | 필드 라벨, 홉 부가 설명, 타임라인 이벤트 |
| **Muted Text** | 보조 메타, 타임스탬프 | `#64748B` (Slate 500) | UTC 타임스탬프, 부가 ID 안내, 비활성 텍스트 |
| **🚨 Critical Alert** | **유일한 적색 하이라이트** | `#FF2D55` (Crimson) | **장애 발생 1개 Hop 카드 + 진단 배너의 장애 원인 텍스트 1줄** |
| **⚡ Primary Action** | **U+ 브랜드 액션** | `#E6007E` (U+ Magenta) | **최상단 1순위 복구 버튼 (유일한 마젠타)** |
| **✅ Success/Normal** | 복구 완료 및 정상 표시 | `#10B981` (Emerald) | 복구 성공 메시지, 작은 정상 인디케이터 점(Dot) |

## 2. 대시보드 내 인포그래픽 & 차트 도입 후보 발굴 (Evaluation)

사용자께서 올려주신 레퍼런스 이미지처럼 **"한눈에 상황을 직관적으로 읽을 수 있는 시각화"**를 위해, 현재 대시보드 데이터(Mock)에서 차트화할 수 있는 요소들을 전수 평가했습니다.

### 2.1 적용 후보 5종 상세 평가

| # | 시각화 요소 | 보여주는 질문 (판단 가치) | 추천 차트 형태 | 데이터 원천 (현행 데이터) | 추천 여부 |
|---|---|---|---|---|:---:|
| **①** | **End-to-End 지연시간 폭포수 차트**<br>*(Latency Waterfall / Bar)* | **"어느 구간에서 시간이 병목되었는가?"**<br>(OEM 처리 0.1s vs MNO 페이징 대기 3s vs 타임아웃 90s) | **가로 스택형 지연 막대 바 (Latency Bar)**<br>(Hop 1~5 소요시간을 1줄 바 그래프로 누적 표현) | `timeline` 내 밀리초 단위 타임스탬프 차이 (0.11s, 0.4s, 3.5s, 90s) | **★ 강력 추천 (1순위)** |
| **②** | **차량 배터리 & LTE RSRP 신호 게이지**<br>*(Battery & RF Gauge)* | **"차량 모뎀과 배터리 상태가 정상 임계치 이상인가?"** | **세미 도넛 게이지 (Semi-Donut Ring)**<br>(12.4V 정상 / 11.8V 미만 Deep Sleep 임계선 표시, RSRP -84dBm) | `vehicle.batteryVoltage` (12.4V, 11.5V, 14.1V)<br>`hops[4].detailItems` (RSRP -84, -118) | **★ 강력 추천 (2순위)** |
| **③** | **As-Is vs To-Be 리드타임 비교 인포그래픽**<br>*(MTTR Comparison Graphic)* | **"이 플랫폼으로 업무 시간이 얼마나 단축되었는가?"** | **대비 수평 바 차트 (26시간 vs 5분)**<br>(기존 소요시간과 개선 소요시간의 극적 대비) | `asIsLeadTime` (26h / 192h)<br>`toBeLeadTime` (5m / 24h) | **★ 추천 (3순위)** |
| **④** | **기지국 무선 Paging & 상향 패킷 카운터**<br>*(Signaling Packet Counter Meter)* | **"기지국 신호가 전파로 나갔는가? 차량이 패킷을 쐈는가?"** | **미니 숫자 카운터 & 상태 미터**<br>(RF Paging 송출: 0건 빨간 경고 / Uplink HTTPS: 14건 초록) | `enodeb_rf_paging_sent_count`<br>`uplink_https_packets_from_tcu` | **보류 (텍스트로 충분)** |
| **⑤** | **장식적 네트워크 토폴로지 / 도넛 차트**<br>*(레퍼런스 중앙 나무 일러스트 형태)* | "전체 연결망의 심미적 연출" | 복잡한 노드 그래프 / 원형 도넛 차트 | 현재 단일 차량 진단에는 전체 통계 데이터 없음 | **❌ 비추천 (인지 방해)** |

## 3. 최종 추천 Top 3 인포그래픽 스펙 (무거운 외부 라이브러리 없이 순수 CSS/SVG 구현)

### 🥇 1. E2E 5-Hop 지연시간 폭포수 바 (End-to-End Latency Waterfall Bar)
- **배치 위치**: 5-Hop 상태 카드와 한글 진단 배너 사이
- **표현 방식**: 단일 가로 라인 위에 5개 구간의 소요 시간(ms/초)을 비율별로 나열.
  - 예: `[Hop 1 앱: 0.1s] ── [Hop 2 클라우드: 0.1s] ── [Hop 3 SMS-C: 0.4s] ── [Hop 4 MNO 코어: 3.5s 🛑 병목 지점] ── [Hop 5 단말 대기: 90s 타임아웃]`
  - 병목이 발생한 구간(MNO 코어망 SGs 지연 또는 타임아웃)이 **빨간색 확장 바**로 직관적으로 드러남.

### 🥈 2. 단말 텔레메트리 듀얼 게이지 (배터리 전압 & LTE 수신 감도 RSRP)
- **배치 위치**: ID Cross-Reference 카드 우측 상단
- **표현 방식**: 레퍼런스 이미지 우측 상단의 도넛 형태를 벤치마킹한 **컴팩트 듀얼 아크(Semi-Circle Gauge)**.
  - **게이지 1 (배터리)**: 12.4V 표시 (11.8V 안전선 이상: 모노톤 실버 / 11.5V 방전 절전: 앰버 경고)
  - **게이지 2 (LTE RSRP)**: -84 dBm (우수 신호: 실버 / -118 dBm 지하 음영: 앰버 경고)
  - 텍스트 숫자로만 적혀 있던 것을 계기판 형태 게이지로 표현하여 하드웨어/음영 여부를 1초 만에 판단.

### 🥉 3. MTTR 리드타임 단축 인포그래픽 배너
- **배치 위치**: 상단 프리셋 칩 바로 아래
- **표현 방식**: 기존 텍스트 태그(`26시간 ➔ 5분`)를 **비교 막대 인포그래픽**으로 전환.
  - 상단 긴 막대: 기존 As-Is (26시간 소요, 옅은 회색 라인)
  - 하단 극단축 막대: 플랫폼 To-Be (5분 해결, U+ 마젠타 포인트)
  - "몇 % 단축(99.6% 절감)" 뱃지와 함께 시각적 ROI 전달.
